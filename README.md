# 🚀 Akash Manda's Full-Stack Developer Portfolio

A modern, responsive portfolio showcasing full-stack development skills with React, Angular, Tailwind CSS, and other cutting-edge technologies.

## 🎯 Portfolio Versions

### 1. **React + Tailwind CSS Version** (`/portfolio-react`)
- Modern React application with Vite
- Fully responsive design with Tailwind CSS
- Dark mode toggle
- Smooth scrolling navigation
- Comprehensive skills showcase
- Interactive project cards

### 2. **Rainbow Spectrum HTML Version** (`/Rainbow_Spectrum`)
- Colorful gradient-based design
- Pure HTML/CSS/JavaScript
- Dark mode support
- Responsive layout
- Rainbow color scheme

## 🚀 Quick Start

### React Version
```bash
cd portfolio-react
npm install
npm run dev
```

### HTML Version
Simply open `Rainbow_Spectrum/index.html` in your browser, or serve it with any HTTP server.
